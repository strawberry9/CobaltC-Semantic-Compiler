# Continuing the project goal

When the user says **“continue with goal”**, resume the **single-module core semantic milestone** defined in [docs/goal.md](docs/goal.md). Read that file and [docs/implementation.md](docs/implementation.md), inspect the actual repository state, and carry out the next bounded phase.

The user requires stopping after each completed phase and waiting for confirmation before starting another. A request to “continue with goal” authorizes one phase, not an indefinite loop. Update the goal handoff with results, validation, remaining limitations, and the next recommended phase before stopping.
